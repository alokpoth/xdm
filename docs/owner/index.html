Privacy & Data Collection Disclosure

XDM Turbo implements strict data minimization. We collect only what is strictly required to enforce single-device and multi-seat licensing:

  • Anonymized SHA-256 hardware identifier (derived from system GUID/motherboard, no personal files/MACs).
  • Computer host name and OS platform (for customer device management).
  • Client application version (for security patch auditing).
  • Last-seen heartbeat timestamp (used solely to determine live seat usage).

We never inspect, collect, or transmit user downloads, URLs, browsing history, files, passwords, or personal identity without explicit opt-in consent.
