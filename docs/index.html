Frequently Asked Questions

Got questions? We've got answers.

Is XDM Turbo really 100% free with all PRO features?
Yes! XDM Turbo is completely free and open-source. All features, including 64 parallel connections, universal 4K video sniffer, bandwidth limiter, and queue scheduling are activated under the universal Lifetime PRO license out of the box with zero subscriptions.
How does 64-stream parallel acceleration work?
Standard browsers request files as one single HTTP stream, meaning your speed is limited by server latency and TCP throughput throttles. XDM Turbo splits the file into 64 simultaneous HTTP Range segments and downloads them all in parallel, maxing out your ISP bandwidth limit.
Can I install XDM Turbo on school/office PCs without Admin rights?
Yes! The Windows Setup installer is compiled with standard asInvoker execution level. It installs straight into your local user AppData folder without ever requiring administrator rights, password prompts, or UAC permission blocks.
Why does Windows SmartScreen show a blue warning?
As an open-source community project without an expensive corporate Extended Validation (EV) certificate, Windows SmartScreen may show "Windows protected your PC" on newly released binaries. Simply click "More info" ➔ "Run anyway". All binaries are 100% clean, virus-free, and open source on GitLab.
How do I connect the Chrome / Edge / Brave extension?
Open XDM Turbo and click the "Browser" button on the top navbar. Click "1-Click Register Extension" for your installed browser, or load the unpacked extension folder in Developer Mode. The video grabber overlay will immediately appear over media players.
